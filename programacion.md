## PROGRAMACIÓN 

### 15. Tipos de datos primitivos en Java 
byte, short, int, long, float, double, char y boolean. 

### 16. Estructuras de control de flujo 
if, else, switch y bucles como for, while y do-while controlan la ejecución del programa. 

### 17. Importancia de nombres significativos 
Facilitan la lectura, mantenimiento y comprensión del código. 

### 18. ¿Qué es la Programación Orientada a Objetos? 
Es un paradigma que organiza el código en objetos que representan entidades reales. 

### 19. Cuatro pilares de la POO 
Encapsulamiento, herencia, polimorfismo y abstracción. 

### 20. ¿Qué es la herencia en Java? 
Permite que una clase herede atributos y métodos de otra. 

### 21. Modificadores de acceso en Java 
public, private, protected y default. 

### 22. ¿Qué es una variable de entorno? 
Es un valor almacenado en el sistema que se usa para configurar aplicaciones.
